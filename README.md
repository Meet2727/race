# Realistic 3D Female Character Studio & Customizer (v2.0)

## What's Included in This Package
- `index.html`, `style.css`, `script.js` — Cleanly separated modular architecture.
- `assets/female_fullbody.obj` — Pre-built smooth anatomical full-body 3D female mesh.
- `assets/character1_3d.obj` & `assets/character2_3d.obj` — Your two uploaded character images converted directly into 3D sculpted `.obj` meshes!
- `assets/character1_depth.jpg`, `character1_normal.jpg`, `character2_depth.jpg`, `character2_normal.jpg` — Generated PBR Depth Displacement & Tangent-Space Normal Maps for realistic 3D lighting and relief.
- **External Rigged 3D Model Support**: Switch between the Anatomical Female Full-Body + 3D Sculpt, Pure 3D Reconstructed `.OBJ`, or an animated external `.GLB` rigged model, plus export your customized 3D model as `.OBJ`.

## How to Run Locally
1. Extract this `.zip` file.
2. Start a local web server in the folder (e.g., VS Code **Live Server** extension, `python -m http.server 8000`, or `npx serve .`).
3. Open `http://localhost:8000` in your browser.
