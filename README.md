# MV 3D — Full-Body Customizable AI System

Interactive 3D Full-Body AI Assistant built with Three.js, modular HTML/CSS/JS, and Web Speech API.

## Files
- `index.html` — 3D Viewport, Full-Body Customizer Studio, and Chat UI
- `style.css` — Responsive dark glassmorphism styling
- `script.js` — Three.js 3D Full-Body Character Builder, Real-Time Customizer, Poses & AI Chat
- `assets/` — Reference portraits (`mv-avatar-1.jpg` & `mv-avatar-2.jpg`)
