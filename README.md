# 3D Character Customizer & Studio

## Project Structure
- `index.html` - Main application structure and UI controls
- `style.css` - Modern dark studio styling
- `script.js` - Three.js WebGL 3D character builder, texture/displacement mapper, and customization logic
- `assets/character1.jpg` & `assets/character2.jpg` - Your uploaded reference character textures

## How to Run Locally & Push to GitHub
1. Extract this `.zip` file into a folder.
2. Because ES Modules (`three.js`) and local textures are loaded, run a local server (for example, using VS Code **Live Server** extension, or `npx serve .`, or `python -m http.server 8000`).
3. Push the folder directly to your GitHub repository and enable **GitHub Pages** to host it live!
