# Subway Runner 3D - Advanced Edition

A fully working, high-performance 3D Endless Runner game inspired by Subway Surfers, built using **Three.js** and Vanilla JavaScript. Fully optimized for desktop and mobile browsers, ready to push to GitHub!

## Features
- **3D Graphics & Lighting:** Powered by Three.js with realistic shadows, fog, and dynamic environment rendering.
- **Smooth Lane Mechanics:** 3-lane switching with fluid keyboard and mobile touch/swipe controls.
- **Dynamic Obstacles & Trains:** Randomized spawning of barriers, low walls, and oncoming trains.
- **Powerups:** Jetpack, Coin Magnet, and 2x Score Multiplier with real-time UI timers.
- **Modern UI & Shop:** Main menu, pause menu, character customization shop, high score tracking, and responsive HUD.
- **GitHub Ready:** Clean directory structure separated into HTML, CSS, and JS.

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser, or run a local server (e.g., Live Server in VS Code).

## Controls
- **Left / Right (A / D / Swipe Left / Swipe Right):** Change Lanes
- **Up (W / Swipe Up):** Jump
- **Down (S / Swipe Down):** Roll / Slide
- **Esc:** Pause Game
