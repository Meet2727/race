# MV — Interactive AI Assistant

**MV** is a modular, Git-ready interactive AI companion web application featuring dual visual avatars, voice interaction (Web Speech API), and a responsive chat interface.

## Folder Structure
- `index.html` — Main application layout
- `style.css` — Responsive dark-mode styling & avatar animations
- `script.js` — Interactive logic, voice synthesis, speech recognition, and optional Gemini API integration
- `assets/` — Contains MV's visual character portraits (`mv-avatar-1.jpg` & `mv-avatar-2.jpg`)

## How to Run Locally
1. Extract the `.zip` file.
2. Open `index.html` in any modern web browser (Chrome, Edge, Brave, Safari).

## How to Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: MV AI System"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/MV-AI-System.git
git push -u origin main
```
